Smarter answers

Optional, off by default. "Go deeper", hard questions and a missing local model can use a stronger cloud model. Secrets are redacted first, and Privacy mode and private pages always keep it off.

The plan options run the official CLI you installed and logged into yourself, with no tools, in an empty folder, and only with a subscription login (never API billing). Follow your provider's terms; this is for personal use.

Gemini has a free tier: create a key at aistudio.google.com. Free-tier requests may be used by Google to improve its products.

Voice

Press ⌥⇧V and talk; Loon listens until you pause. Audio is processed on this Mac and never saved.

Projects

Loon can catch you up ("where did I leave off?") on projects you allow. It only reads them: git history, open TODO items and recent files. Nothing is changed or uploaded.
